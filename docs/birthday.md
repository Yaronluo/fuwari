# 生日小屋

入口：`/birthday/`；「探索 → 生日小屋」的导航项与页脚入口只在农历生日当天显示。首页第一屏介绍之后、文章列表之前，同样只在生日当天显示邀请卡。

## 每年自动切换

- 日期为正常农历九月十三，闰九月不重复庆祝。
- 全部访客以 `Asia/Shanghai`（UTC+8）当天 00:00 至次日 00:00 为准。
- 在访客浏览器中使用 `Intl` 中国农历计算日期，不依赖构建时的日期，也不需要每年更新公历日期或触发重新部署。
- 页面打开期间每秒刷新状态；跨午夜和切回后台标签页后也会更新。
- 平日显示下次生日的公历日期与倒计时；生日当天显示祝福文案。
- 不支持中国农历的浏览器仍展示生日小屋，省略倒计时与首页邀请卡。

## 互动

- Hero：三支蜡烛可逐一点亮／吹灭（全灭时触发彩纸），音乐盒按钮用 WebAudio 现场合成旋律，不加载音频文件；生日当天另有「放一串小烟花」。
- 祝福：三张固定祝福卡任选一张，选中后播放星光动画。祝福不发送、不保存，刷新或重新进入页面后恢复初始状态。
- 生日签：八支签，点开翻面再抽，签文与宜忌均为固定文案。
- 信：点击信封拆开，信纸展开，内容固定。

依照当前需求，不提供自由留言、祝福墙或人数计数，也不提供清单式的待办互动。所有互动都在当前页面内完成，不发送请求、不保存访客数据，不需要数据库；支持键盘操作、`prefers-reduced-motion`、深色模式与移动端布局。

## 修改与验证

- `src/components/BirthdayRoom.svelte`：整页排版、蛋糕与蜡烛、音乐盒、祝福卡、生日签、信与彩纸动画。
- `src/components/BirthdayInvitation.svelte`：首页生日入口。
- `src/utils/birthday.ts`：农历与时区计算。
- `src/config.ts`：导航项 `onlyOnBirthday` 标记与博主昵称。
- `src/components/Navbar.astro`：维护 `html.birthday-day`；`src/styles/main.css` 据此隐藏带 `data-birthday-only` 的导航、移动菜单与页脚条目。

验证命令：

```sh
pnpm test:birthday
pnpm check
pnpm build
pnpm preview --host 127.0.0.1
```

日期测试覆盖中国标准时间午夜、非生日、次年变化、闰九月和倒计时归零。浏览器预览时应检查首页邀请卡、导航进出后的互动、手机布局、深色模式和键盘操作。
